# articulate_ideas_app

A personal learning coach: learn a topic in short chunks, recall and explain it, and review it on a spaced schedule. See [PLAN.md](PLAN.md) for the full product and build plan.

## Stack

Next.js (App Router) + TypeScript, Tailwind CSS + shadcn/ui, Supabase (Postgres), Claude API, Zod.

## Run locally

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev
```

Open http://localhost:3000.
